# Goa by source: descriptive DEV diagnostic

Population: 1472 DEV Goa recipes. Same unvalidated audit-proposal rule and pinned gate-spec hash as the audit; no held-out labels used. Full region/site counts are in `data/quality/quality_manifest.json`.

Largest source: `celebrationinmykitchen`, 621/1472 rows (42.19%). Its text-insufficiency rule fires on 462/621 (74.40%). All other Goa sources combined: 122/851 (14.34%). Goa total: 584/1472 (39.67%).

This documents strong source-associated heterogeneity. It does not establish a causal website effect, recipe defect rate, or a property of Goan food: source mix, language, dish mix and duplicates can differ. The audit rule is not independently validated. Future comparisons should retain source strata, report leave-one-source-out sensitivity and account for duplicate groups; do not tune on frozen K006 outcomes.

ALL includes 1545 Goa rows; DEV includes 1472. Its ALL largest-source share is 646/1545 (41.8%), whereas DEV is 621/1472 (42.2%). These are different denominators, not inconsistent measurements.
